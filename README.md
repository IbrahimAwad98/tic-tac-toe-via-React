# Tic-tac-toe via React

A tic-tac-toe game built with [Next.js](https://nextjs.org) and React. Created with `create-next-app`.

## Getting started

Start the dev server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

The game lives in `app/page.tsx`. The page reloads when you save.
